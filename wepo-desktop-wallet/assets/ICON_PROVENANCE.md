# WEPO Desktop Icon Provenance

Generated on 2026-07-29 with OpenAI's built-in image generation tool for this
project. There was no existing logo, icon, favicon, or image asset in the
repository.

Final project assets:

- `icon.png`: 1254×1254 RGBA source with transparent corners.
- `icon.ico`: Windows ICO containing 16, 24, 32, 48, 64, 128, and 256px images.

The flat chroma-key intermediate was removed after conversion. Validation found
no remaining magenta key-color pixels, and the 32px icon extracted from the
packaged `WEPO Wallet.exe` was pixel-identical to the resized project source.
